
# WorkSphere

WorkSphere is a full-stack Human Resource Management System (HRMS)
project designed to organize employee records, onboarding, attendance,
leave management, approvals, and notifications.

## Project Goals

- Centralize employee information and HR workflows.
- Support role-based access for Super Admins, Admins, HR, and employees.
- Improve onboarding, attendance, leave, and approval workflows.
- Maintain clear records and notifications for important actions.

## Technology Stack

- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Frontend:** React (planned integration)

## Project Status

WorkSphere is under active development. Features, APIs, and
documentation may change as development progresses.
